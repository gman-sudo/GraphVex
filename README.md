# GraphVex

## Financial Transaction Anomaly & Network Intelligence

GraphVex is an explainable financial transaction intelligence system
for identifying anomalous financial behaviour and suspicious
transaction-network patterns.

> Educational / research prototype. GraphVex does not determine
> whether money laundering or financial crime has occurred.

## Status

In Development

## Focus

- Transaction anomaly detection
- Behavioural analytics
- Graph-based network intelligence
- Explainable risk scoring
- Investigation support
